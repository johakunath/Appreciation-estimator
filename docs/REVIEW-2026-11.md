# Review Wertsteigerung Estimator (Stand 2026-11-04)

Scope: Code, Qualität, Token-Effizienz (Multi-AI), Modell/Zahlen/Ergebnisse, UI/Design.
Grundlage: `src/App.jsx` @ `f99ca58`, Modell-Durchläufe aller 125.000 Input-Kombinationen, Screenshots 760px + 390px, zwei Research-Agents (Marktdaten, Methodik).

---

## 1. Kurzfazit

| Bereich | Urteil | Kernproblem |
|---|---|---|
| Modell/Logik | **Nicht belastbar** | Szenario-Reihenfolge bricht (Bear > Base), Gewichte wirkungslos, Spanne zu eng, horizont-unabhängig |
| Ergebnisdarstellung | **Optimistisch verzerrt** | Headline "Netto nach KNK" nominal: Default zeigt **+60k €**, real sind es **−5k €** |
| Zahlen/Content | Teilweise veraltet/inkonsistent | Zins-Text falsch (EZB hat 2026 2× erhöht), Inflation 2,8 % statt 1,9 %, Benchmarks nicht mit Modell verknüpft, Investropa als Quelle |
| Code | Ok für Prototyp | 667 Zeilen Monolith, 153 Inline-Styles, keine Tests, kein Lockfile |
| Token-Effizienz | Mittel | ~11,4k Tokens pro Lesevorgang für jede Änderung; CLAUDE.md beschreibt Gewichte, die der Code nicht nutzt |
| Design | Solide Basis, UX-Mängel | Mobile-Overflow, inaktive Optionen unlesbar (1,66:1 Kontrast), 30× Schrift <13px, viel Jargon |

**Wichtigster Punkt:** Das Tool widerspricht seinem eigenen Prinzip "Anti-Optimismus". Spanne zu schmal, Bear-Case nach unten gekappt, Ergebnis nominal statt real präsentiert.

## 2. Modell & Logik (höchste Priorität)

### 2.1 Bugs (verifiziert per Skript)

| # | Problem | Beleg | Fix |
|---|---|---|---|
| B1 | **Bear > Base und Bull < Base möglich.** `bearRate = max(-2, …)` kappt nur Bear. | Alle Scores 1 + ETW unsaniert: Bear −2,0 / Base −4,0 / Bull −2,4. Tritt in **428 von 125.000** Kombinationen auf. | Floor entfernen, oder Floor auf Base anwenden und Bear ≤ Base erzwingen. Anti-Optimismus spricht für: kein Floor. |
| B2 | **Gewichte (28 %, 20 % …) werden im Ergebnis nicht verwendet.** `totalDelta += d` ohne Gewicht. Gewichte wirken nur auf die Spanne. | Implizite Gewichte aus Delta-Spannweiten: S/D 26 %, Lage-Dyn. 19 %, Infra 10 %, Objekt 14 %, Reg. 12 %, **Zins 19 % (angezeigt 13 %)**. | Gewichtsangaben aus UI + CLAUDE.md entfernen. Stattdessen "max. Einfluss ±x pp" anzeigen. |
| B3 | **Kohärenz beeinflusst die Spanne nicht.** UI sagt "enger Korridor, höhere Konfidenz", Prinzip 4 sagt "Widersprüche weiten Spanne". | Alle 5 (Kohärenz 100 %) und 1/5-Mix (Kohärenz 28 %) haben identische Spanne 1,6. | Kohärenz in Spread einrechnen oder Text korrigieren. |
| B4 | **Toter Code in Entscheidungslogik.** Da Spread ≥ 1,2: `realBear ≥ 0` ⇒ `realBase ≥ 1,2`. Vierter Investment-Zweig nie erreichbar. | Logik-Analyse | Schwellen neu definieren (siehe 2.4). |
| B5 | Haltedauer-Feld springt beim Leeren auf 10, keine Begrenzung bei Eingabe (negativ möglich). | `parseInt(...) \|\| 10` | Lokaler String-State, Clamp 1–40 bei Blur. |
| B6 | Farbe der Empfehlung wird über Emoji-Vergleich `d.icon === "🟢"` bestimmt. | Code | `level: "good" \| "warn" \| "bad"` zurückgeben. |

### 2.2 Methodische Schwächen

| # | Problem | Warum relevant | Empfehlung |
|---|---|---|---|
| M1 | **Spanne zu eng und symmetrisch.** Spread nur 1,2–1,6 pp, unabhängig von allem. | Rollierende 10J-Real-CAGR DE (P10–P90): −1,7 % bis +2,6 % = ±2,1 pp beim **nationalen Index**. Einzelobjekt streut zusätzlich (siehe 3.2, 4.1). | Horizontabhängige, asymmetrische Spanne (siehe 4.2). |
| M2 | **Horizont-unabhängig.** Zins- oder Momentum-Faktor wirkt 15 Jahre lang konstant p.a. | Zinsänderung ist primär ein einmaliger Niveaueffekt; Gentrifizierungs-Momentum läuft aus. Bei 15J × 1,2 pp entsteht ~20 % Wertunterschied aus einer Zinsmeinung. | Faktor-Deltas mit Horizont abklingen lassen: zyklische Faktoren (Zins, Momentum) als Effekt auf die ersten 3–5 Jahre, danach Rückkehr zum Anker. |
| M3 | **Kein Cap auf Gesamtanpassung.** Bull bis 10,1 % nominal / 7,8 % real p.a. über 15 Jahre möglich. | Für ein Anti-Optimismus-Tool unplausibel. | Summe der Deltas cappen, z. B. ±2,5 pp real. |
| M4 | **Doppelzählung Objekttyp × Objektqualität.** Neubau +0,5 und Qualität 5 (+0,8) beschreiben dasselbe. Ebenso unsaniert −0,4 und Qualität 1 (−0,8). | Bis 1,3 pp p.a. doppelt. | Entweder Typ-Modifier oder Qualität-Score, nicht beides. Vorschlag: Typ setzt den Benchmark-Anker, Qualität adjustiert innerhalb. |
| M5 | **Neubau-Aufschlag +0,5 % p.a. nicht belegt.** Einzelne Neubau-ETW altert; Neubauprämie (Berlin +47 %) erodiert. Neubau ist nur im Abschwung stabiler. | Siehe 3.2, 4.1. | Neubau-Modifier ≤ 0 relativ zu Bestand über 10–15J, oder explizit als "Neubauprämie-Verlust" modellieren. |
| M6 | **Inflation als Basis = Annahme "Immobilie ist perfekter Inflationsschutz".** Real-Rate ist komplett unabhängig von Inflation. | 2022/23 zeigte das Gegenteil: hohe Inflation + steigende Zinsen = real −20 %+. Inflation und Zins sind korreliert, im Modell unabhängig. | Real-Anker statt Inflationsanker: Base real = Segment-Benchmark real + Adjustments; nominal = real + Inflation. |
| M7 | **Benchmark-Tabelle (Anleitung) ist nicht mit dem Modell verbunden.** | Altbau unsaniert: Benchmark Bear −1 %, Modell-Default Bear +1,3 %. Neubau: Benchmark 2/4/6, Modell 2,1/3,3/4,5. | Anchor-and-adjust: Segment wählen → Benchmark als Start → Faktoren adjustieren begrenzt. |
| M8 | **CapEx im Wertsteigerungsprozentsatz versteckt** (unsaniert −0,4 %). | Sanierungsbedarf ist ein €-Betrag, kein Renditeabschlag. Wertsteigerung setzt Instandhaltung voraus (~1–1,5 % des Gebäudewerts p.a.). | Optionales Feld "Erwarteter CapEx (€)" und Hinweis Instandhaltung. |
| M9 | **Zinsentwicklung ist Makro, kein Objektfaktor.** Gleicher Wert für jedes Objekt, aber pro Objekt bewertet. | Verleitet zu Meinungs-Tuning. | Als globale Einstellung neben Inflation führen, Default 3, mit Hinweis "nur mit starker Überzeugung ändern". |
| M10 | Real-Rate = nominal − Inflation (Näherung). | Bei 2–3 % vernachlässigbar (≤0,1 pp). | Optional exakt: (1+n)/(1+i)−1. Niedrige Priorität. |

### 2.3 Ergebnisdarstellung verzerrt optimistisch

Default (150k €, 15 J, Berlin-Defaults):

| Szenario | Netto nach KNK nominal (angezeigt) | Netto nach KNK real | Real inkl. 3,57 % Verkaufskosten |
|---|---|---|---|
| Bear | **+23.825 €** (grün) | −31.501 € | −36.321 € |
| Base | **+60.480 €** (grün) | −4.848 € | −10.619 € |
| Bull | +103.642 € | +26.655 € | +19.759 € |

- Grün angezeigter Bear-Gewinn ist real ein Verlust von ~20 % des Kaufpreises.
- "Break-even ~7 Jahre" im Bear-Case ist nominal; real gibt es keinen Break-even.
- Fehlend: Verkaufskosten, Spekulationssteuer §23 EStG (Kapitalanlage, Verkauf < 10 J), Instandhaltung.

**Fix:** Netto-Gewinn real als Hauptzahl, nominal sekundär. Break-even real berechnen (und mit Zinseszins: `ln(1+KNK)/ln(1+r)`). KNK-% editierbar (ohne Makler ~7,5 %).

### 2.4 Entscheidungslogik

- Schwellen hart codiert (0,5 / 1,0), teilweise unerreichbar (B4).
- Eigennutzung-Modus ignoriert den Bear-Case komplett.
- Vorschlag: Empfehlung nur aus `realBear` und `realNetBear` (nach KNK, Haltedauer) ableiten. Drei Stufen: real erhalten / leichter realer Verlust / deutlicher realer Verlust.

## 4. Methodik: Best Practice und Modell-Vorschlag v4

### 4.1 Evidenz

| Thema | Befund | Quelle | Stärke |
|---|---|---|---|
| Zins-Effekt | +1 pp Hypothekenzins → ca. −5 % Preisniveau nach ~2 Jahren (−9 % bei niedrigem Ausgangsniveau). **Einmaliger Niveaueffekt**, kein Dauer-Drag p.a. | [EZB Bulletin 6/2022](https://www.ecb.europa.eu/pub/economic-bulletin/focus/2022/html/ecb.ebbox202206_04~786da4a23a.bg.html), BVR (~−2 %/pp DE) | gut belegt |
| Momentum / Mean Reversion | Momentum über ~1 J, Mean Reversion über ~5 J | [Glaeser & Gyourko](https://www.nber.org/papers/w12787.pdf), Case & Shiller 1989 | gut belegt |
| Langfrist-Anker | Reale Hauspreise langfristig ~flach bis +1 % p.a.; Anstieg nach 1950 zu ~80 % aus Bodenwert | [Knoll/Schularick/Steger AER 2017](https://www.aeaweb.org/articles?id=10.1257/aer.20150501) | gut belegt |
| Gebäudealterung | ~2 % p.a. netto (US), deutlich weniger bei hohem Bodenanteil (~0,3–0,9 %) | Harding/Rosenthal/Sirmans 2007, Wilhelmsson 2008 | belegt, DE-spezifisch nicht gefunden |
| Einzelobjekt-Risiko | Objektspezifischer Schock ~11–18 % des Preises, einmalig beim Verkauf, wächst nicht mit Haltedauer → p.a. bei 5 J ~±2,5 pp, bei 15 J ~±0,8 pp | [Giacoletti, RFS 2021](https://econpapers.repec.org/RePEc:oup:rfinst:v:34:y:2021:i:8:p:3695-3741.) | gut belegt (US) |
| Downside-Tail | Wird breiter mit Überbewertung, Kreditwachstum, strafferen Finanzierungsbedingungen | [IMF WP 20/11](https://www.imf.org/en/publications/wp/issues/2020/01/17/predicting-downside-risks-to-house-prices-and-macro-financial-stability-48932) | gut belegt |
| Stresstest-Praxis | Einmalige Niveauschocks, z. B. EBA 2025 adverse: DE Wohnen −13 % über 2025–27 | EBA 2025 | gut belegt |
| Statische Merkmale | Ist-Infrastruktur und Objektqualität sind im Kaufpreis **bereits eingepreist**; nur Veränderungen treiben Wachstum | Hedonik/Kapitalisierungstheorie | gut belegt |
| Bankpraxis | Beleihungswert schließt spekulative Wertsteigerung aus (§3 BelWertV) | [§3 BelWertV](https://www.gesetze-im-internet.de/belwertv/__3.html) | Fakt |
| Unsicherheitskommunikation | Quantil-Dot-Plots/Fan-Charts → bessere Entscheidungen als Punkt + Text; Unsicherheit anzeigen senkt Vertrauen kaum | [Fernandes et al. CHI 2018](https://idl.uw.edu/papers/uncertainty-bus), van der Bles 2019 | gut belegt |

### 4.2 Modell v4 (Vorschlag, bleibt bei 6 Inputs, rein client-seitig)

Die Zahlen sind kalibrierte Schätzungen auf Basis der Evidenz oben, keine geschätzten Parameter.

| Baustein | Heute | v4 |
|---|---|---|
| Anker | Inflation (= real 0 %) | **Segment-Benchmark real** (z. B. ETW Innenstadt Bestand +0,5 %, Randlage 0 %), nominal = real + Inflation |
| Objekttyp | Modifier p.a., doppelt mit Qualität | Wählt den Anker; kein zusätzlicher Modifier |
| Angebot/Nachfrage, Lage-Dynamik | konstant p.a. | Tilt mit Abklingen (Halbwertszeit ~4–5 J) → p.a.-Effekt sinkt mit Haltedauer |
| Zinsen | −1,2 … +1,0 % p.a. konstant | **Niveauschock** −12 / −6 / 0 / +5 / +9 % in J 1–2, auf Haltedauer annualisiert; globale Einstellung |
| Infrastruktur, Objektqualität | verschieben Base | Verschieben primär den **Bear-Abstand** (±0,5 pp): gute Lage/Qualität = resilienter |
| Gesamt-Tilt | ungedeckelt (bis +6,2 % real) | Cap ±1,5 pp p.a. (≥10 J), ±3 pp (5 J) |
| Spanne | 1,2–1,6 pp, symmetrisch, horizontunabhängig | Horizontabhängig, asymmetrisch: 5 J −4,5/+3,5 pp, 10 J −3/+2,5, 15 J −2,5/+2 pp; ×1,0–1,5 bei extremen/widersprüchlichen Inputs |
| Floor | Bear ≥ −2 % | Kein Floor |
| Stress | – | Separat ausgewiesen: einmalig −15 % nominal in J 1–3 |
| Ergebnis | nominal Netto nach KNK | **Real Netto nach KNK + Verkaufskosten**, Break-even-Wertsteigerung p.a. für Haltedauer, §23-Hinweis < 10 J (Kapitalanlage) |

**Sanity-Check v4 mit Berlin-Default (ETW Innenstadt Bestand, 15 J):** Base real ~+0,5–0,8 %, Bear real ~−1,8 %, Bull real ~+2,5 %. Deckt sich mit der historischen rollierenden 15J-Spanne (−1,8 % bis +2,9 %).

**Nicht tun:** Monte-Carlo, Datenfeeds, mehr Faktoren. Analytische Quantile reichen.
